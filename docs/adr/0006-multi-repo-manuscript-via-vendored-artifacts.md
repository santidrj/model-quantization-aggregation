# Multi-repo manuscript via vendored artifacts

The EMSE manuscript LaTeX lives in a separate private repository (`model-quantization-manuscript`); this repository remains the public Zenodo replication package. We rejected a monorepo and git submodules: the manuscript stays private forever, while readers cite the paper and the Zenodo DOI only—never a manuscript git URL. Generated figures and allowlisted `.tex` table fragments are vendored into the manuscript under `artifacts/` and refreshed by a sync script. Day-to-day drafting syncs from this repo’s `review` branch (SHA recorded in the manuscript pin); Zenodo versions are used only on explicit milestone or submission sync. Author macros, bibliography, and prose stay in the manuscript; this repo owns computation and fragment generation only.
