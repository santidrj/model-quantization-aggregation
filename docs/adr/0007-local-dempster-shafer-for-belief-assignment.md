# Local Dempster–Shafer combination for belief assignment

Evidence Factory cannot assign custom simple-support masses—undiscounted unsplit \(B\), mass-preserving root \(1-(1-B)^{1/N}\), or equitable \(B/N\)—without sample-size and variability discounts, so belief-assignment synthesis is computed locally. Combination follows Santos (2015) SSM: Dempster's rule applied pairwise on the intensity frame \(\{SN, NE, WN, IF, WP, PO, SP\}\), renormalized after each step, in Evidence Factory aggregation-turn order (`data/processed/evidence-factory-aggregation-order.txt`), with masses left unrounded. Reported conflict is that last pairwise \(K\). The original local replication used Evidence Factory-compatible hypothesis selection: singleton and focal adjacent-compound candidates with the 75% threshold. The published analogue matches Evidence Factory aggregated evidence 329074 on intensity, integer-percent belief, last-step \(K\), and evidence-model count. ADR 0008 records why literature-based comparisons now use a separate Santos hypothesis-selection policy.
