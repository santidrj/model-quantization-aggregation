# Single validated synthesis file for manuscript numbers

Manuscript tables, forest-plot Aggregated overlays, subgroup provenance, sensitivity values, and result-section counts are generated from one committed JSON file (`data/processed/validated-synthesis.json`). The file is produced by local Dempster–Shafer pooling of processed evidence models under published-analogue masses and the Evidence Factory-compatible selector. Automated assertions check corpus size, per-effect study and model counts, intensity, belief, conflict, and belief delta, and that the appendix published-analogue column matches the main table. Leave-one-study-out omits, for each effect, the study whose removal yields the smallest remaining belief; if no omission decreases belief, every candidate omission is reported. Hand-authored Aggregated rows and Santos-selected analogue columns are not manuscript authorities.
