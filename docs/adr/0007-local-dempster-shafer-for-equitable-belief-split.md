# Local Dempster–Shafer combination for equitable belief split

Evidence Factory cannot assign each evidence model mass \(B/N\) without sample-size and variability discounts, so synthesis for the equitable belief split is computed locally. Combination uses Dempster's n-fold rule on the SSM intensity frame \(\{SN, NE, WN, IF, WP, PO, SP\}\), with masses left unrounded. A published analogue (processed \(B'\)) is the reproduction gate: intensity and evidence-model counts match Table `tab:general-results`, integer-percent belief matches except Inference Power Draw (71% local vs 72% published), and n-fold conflict \(K=m(\emptyset)\) does not match Evidence Factory's conflict column. Until that gate passes, split figures are not manuscript results.
