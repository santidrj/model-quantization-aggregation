# Local Dempster–Shafer combination for equitable belief split

Evidence Factory cannot assign each evidence model mass \(B/N\) without sample-size and variability discounts, so synthesis for the equitable belief split is computed locally. Combination follows Santos (2016) SSM: Dempster's rule applied pairwise on the intensity frame \(\{SN, NE, WN, IF, WP, PO, SP\}\), renormalized after each step, in Evidence Factory aggregation-turn order (`data/processed/evidence-factory-aggregation-order.txt`), with masses left unrounded. Reported conflict is that last pairwise \(K\). Hypothesis selection uses focal adjacent compounds and drops a compound when a contained singleton holds \(\ge 75\%\) of its belief (thesis §5.3.2); non-focal compounds are not candidates. The published analogue matches Evidence Factory aggregated evidence 329074 on intensity, integer-percent belief, last-step \(K\), and evidence-model count.
