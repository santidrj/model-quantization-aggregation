# Variability discount uses Kvålseth \(V_2\), not relative IQR

The published variability reliability is \(\alpha_v=e^{-k V_2}\) with \(V_2=\sigma/\sqrt{\sigma^2+\mu^2}\) (Kvålseth’s second-order coefficient of variation) on experimental-unit relative improvements, \(k=0.1\), and \(\alpha_v=1\) when cluster \(n_{\mathrm{eff}}\le 4\). The previous main argument \(\lvert\mathrm{IQR}/(\mu+\varepsilon)\rvert\) is rejected: it is ill-conditioned for near-zero means (for example S14 accuracy) and is not a standard relative-dispersion measure for signed RI%.

**Considered options.** Floored \(\max(|\mu|,\delta)\) fixes the blow-up only with a domain \(\delta\) and is not a named literature statistic. Heath–Borowski PV and Bonett CQV / Arachchige RCVQ require non-negative support, so raw unbounded RI% (corpus minima below \(-100\%\)) need an embedding; that adds a transform the paper would have to invent. \(V_2\) is defined for all real-valued samples, bounded in \([0,1]\), and stable as \(\mu\to 0\). The exponential map and \(k=0.1\) are retained from the ESEM precursor; methods cite Kvålseth for the argument and Shafer/SSM for the discounting operation, without claiming a single external paper owns this exact \(\alpha_v\).

**Consequences.** Sensitivity grids \(k\) around \(\{0.05,0.1,0.5\}\). Processed effect beliefs, `PUBLISHED_TABLE` gates, validated-synthesis artifacts, appendix worked examples, and Evidence Factory sync must be regenerated after the code change. Near-zero correctness effects that previously collapsed under relative IQR now keep \(\alpha_v\approx e^{-k}\) and can move the pooled accuracy intensity (for example from \(\{WN,IF\}\) toward \(\{IF\}\)). ADR 0009’s variability-discount sentence is superseded by this decision.
