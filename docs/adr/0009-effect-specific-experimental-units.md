# Effect-specific experimental units, cluster units, and forest-plot \(n_{\mathrm{eff}}\)

Effective sample size, belief discounts, forest-plot annotations, and unit-level confidence intervals must use a consistent inferential unit per effect. A single study-wide `GROUPING_COLUMNS` tuple is insufficient when a metric is invariant to evaluation context (for example storage size across HumanEvalPack tasks), when repeated measurement runs inflate raw row counts without increasing generalizability, or when several evaluation tasks nest inside one model family.

**Policy.** Global defaults assign full `GROUPING_COLUMNS` to task- and execution-dependent metrics. `storage_size` drops evaluation-context columns (`Dataset`, `dataset`, `task`) from grouping; optional `METRIC_GROUPING_OVERRIDES` on a paper class override defaults when documented. Replicate rows (`EXPERIMENT_RUN_KEY`) are averaged within an experimental unit before mean, IQR, \(\alpha_n\), \(\alpha_v\), CIs, and forest-plot \(n_{\mathrm{eff}}\).

Two grains are distinguished:

- **Experimental unit.** The grouping-column combination used to pair each quantized run with its baseline. The evidence-model mean and IQR are the unweighted mean and IQR of experimental-unit relative improvements.
- **Cluster unit.** The experimental-unit key after dropping only evaluation-context columns (`Dataset`, `dataset`, `task`). Device, compute unit, frequency, library, and filter multiplier stay. Artifact-invariant metrics already omit those columns, so their cluster key matches the experimental unit.

Sample-size discount, variability-discount cutoff, and forest-plot \(n_{\mathrm{eff}}\) count **cluster units** with a non-null improvement for that metric (for example S10 accuracy on three classification models, DSC on three segmentation models). Evidence-model forest-plot intervals are two-sided 95% intervals for the experimental-unit mean: Student's \(t\) (`DescrStatsW.tconfint_mean`) when each experimental unit is its own cluster, and cluster-robust OLS (`statsmodels` intercept-only, `cov_type="cluster"`) when experimental units nest inside clusters. Intervals are omitted when \(n_{\mathrm{eff}}<2\) or all unit values are numerically identical. Aggregated rows show an em dash for \(n_{\mathrm{eff}}\) because pooled units across studies are not defined, and their bars are SSM intensity ranges rather than confidence intervals.

The saturation parameter \(n_0\) is 3, the integer nearest \(2/\ln 2\), so two independent cluster units sit at the median of \(\alpha_n=1-e^{-n_{\mathrm{eff}}/n_0}\) rather than at the characteristic point \(1-1/e\). The third quartile of cluster \(n_{\mathrm{eff}}\) over evidence-model effects remains a diagnostic of the evidence body; it does not choose \(n_0\). The variability-discount formula is unchanged: denominator \(\mu+\varepsilon\), \(k=0.1\), cutoff \(n_{\mathrm{eff}}>4\) on cluster \(n_{\mathrm{eff}}\).
