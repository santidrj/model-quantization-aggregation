# Lazy fetch of external paper data from remote archives

Evidence extraction needs study-provided datasets under each paper's external data folder, but we do not commit those files (copyright / size). Some papers only ship the needed tables inside large public Zenodo zips. We decided on a general, Paper-owned mechanism: an optional generic descriptor (archive URL + exact archive-relative member paths → local filenames) that lazily ensures required files on first `scan_csv` / `read_csv` / `read_excel`, downloading the archive only when members are missing, extracting those members, and discarding the archive—never overwriting files already present. Papers without a descriptor still require the conventional `paper-data.csv` and fail with a pointer to their external README if it is absent; fetch failures fail loudly. We rejected per-paper one-off scripts, README scraping, a parallel registry, downloading whole archives into `data/external/`, and Zenodo-specific types on `Paper`, so the interface stays small and reusable while first wiring Alizadeh and Gonzalez.
